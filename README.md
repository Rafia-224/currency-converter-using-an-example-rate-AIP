# currency-converter-using-an-example-rate-AIP
currency converter using an example rate AIP built with python
This project is a simple Currency Converter built with Python. It converts an amount from one currency to another using an example exchange rate.

Features
Converts currency quickly and easily.
Uses a simple example exchange rate.
Takes the amount as user input.
Displays the converted amount.
Beginner-friendly Python project.
Example

If 1 USD = 280 PKR, entering 10 USD will give:

10 USD = 2800 PKR

Technologies Used
Python
Basic arithmetic
User input and output
Purpose

This project is designed to help beginners understand variables, input, calculations, and conditional logic in Python.

Note

The exchange rate used in this project is only an example rate and may not represent the current market rate.
